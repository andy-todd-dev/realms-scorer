# Effect mapping

This describes the engine as of when it was written. `src/domain/card.ts` and `src/domain/score.ts` are the source of truth: if something listed as missing now exists, use it.

## Wording the model supports

Helpers are in `src/infrastructure/driven/decks/card-definitions.ts`. `card("x")` is the local helper in `base.cards.ts`.

| Printed wording                                                         | Effect                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `+N` or `-N`, unconditional                                             | `points(N)`                                                                                                                                                                                                                                                                                                                                                                                                              |
| "+N for each X"                                                         | `points(N, { per: suit("x") })`                                                                                                                                                                                                                                                                                                                                                                                          |
| "+N for each X and Y"                                                   | two effects: `points(N, { per: suit("x") })`, `points(N, { per: suit("y") })`                                                                                                                                                                                                                                                                                                                                            |
| "+N with X", "+N with any one X"                                        | `points(N, { when: present(suit("x")) })` (no `per`, since it applies once)                                                                                                                                                                                                                                                                                                                                              |
| "+N with the named card"                                                | `points(N, { when: present(card("x")) })`                                                                                                                                                                                                                                                                                                                                                                                |
| "-N unless with X"                                                      | `points(-N, { when: absent(suit("x")) })`                                                                                                                                                                                                                                                                                                                                                                                |
| "+N if no X"                                                            | `points(N, { when: absent(suit("x")) })`                                                                                                                                                                                                                                                                                                                                                                                 |
| "+A for each X. OR +B for each X if with Y"                             | `points(A, { per, when: absent(Y) })`, `points(B, { per, when: present(Y) })`                                                                                                                                                                                                                                                                                                                                            |
| "+N with both X and Y"                                                  | `points(N, { when: allOf(present(...), present(...)) })`                                                                                                                                                                                                                                                                                                                                                                 |
| "+N with X or Y"                                                        | `points(N, { when: anyOf(present(...), present(...)) })` (applies once, however many match)                                                                                                                                                                                                                                                                                                                              |
| "+A with X, or +B with Y", where both could hold and X takes precedence | `points(A, { when: present(X) })`, `points(B, { when: allOf(absent(X), present(Y)) })`                                                                                                                                                                                                                                                                                                                                   |
| "+N if every non-blanked card is a different suit"                      | `points(N, { when: allSuitsDifferent })` (includes the card's own suit, Wild counts as a suit, and part-built hands qualify)                                                                                                                                                                                                                                                                                             |
| "+A for a 3-card run, +B for a 4-card run", on base strengths           | `baseStrengthRun([{ length: 3, points: A }, { length: 4, points: B }])` (includes the card's own strength; duplicates do nothing; only the longest run pays, at its highest tier, without adding up; longer than the top tier pays nothing extra)                                                                                                                                                                        |
| "The sum of the base strength of all X"                                 | `sum(suit("x"), "baseStrength")` (never counts its owner; blanked cards add nothing; other cards' bonuses and penalties stay out of it)                                                                                                                                                                                                                                                                                  |
| "BLANKS all X and Y"                                                    | `blank(suit("x"), suit("y"))`                                                                                                                                                                                                                                                                                                                                                                                            |
| "BLANKS all X except the named card"                                    | `blank(except(suit("x"), card("y")))` (`except` works wherever a suit matcher does, including `per`, `when` and clears)                                                                                                                                                                                                                                                                                                  |
| "BLANKS the named card"                                                 | `blank(card("x"))`                                                                                                                                                                                                                                                                                                                                                                                                       |
| "Blanked unless with X"                                                 | `blankSelf({ when: absent(suit("x")) })`                                                                                                                                                                                                                                                                                                                                                                                 |
| "Blanked with any X"                                                    | `blankSelf({ when: present(suit("x")) })`                                                                                                                                                                                                                                                                                                                                                                                |
| "Clears the penalty on all X"                                           | `clearPenalty(suit("x"))`                                                                                                                                                                                                                                                                                                                                                                                                |
| "Clears the word X from all penalties"                                  | `clearPenaltySuitWord("x")` (plurals in a card's text don't matter, because effects name the suit)                                                                                                                                                                                                                                                                                                                       |
| "Clears the penalty on any one X or Y" (the player chooses)             | `clearPenalty(chosenCard)` plus `choice: chooseCard(fromHand, suit("x"), suit("y"))`, as Island does                                                                                                                                                                                                                                                                                                                     |
| "Take one X or Y from the discard area and add it to your hand"         | `preScoring: [addToHand(chosenCard)]` plus `choice: chooseCard(fromDiscardArea, suit("x"), suit("y"))`, with the printed text in its section and `effects: []`, as Necromancer does. List the card in the variant's `preScoring` order. The chosen card joins the hand before scoring and doesn't count towards the hand size. Any card in the variant's deck that isn't in the hand counts as being in the discard area |
| "May duplicate the name and suit of any one X or Y in the game"         | `preScoring: [take(chosenCard, "name", "suit")]` plus `choice: chooseCard(fromGame, suit("x"), suit("y"))`, with the printed text in its section and `effects: []`, as Shapeshifter does. List the card in the variant's `preScoring` order. It keeps its own ID, base strength and effects; taking the name makes rules naming the chosen card match it, and the choice may take a card in the hand                     |

**"OR" needs care.** Effects don't exclude each other on their own: every effect whose condition holds is added. King and Queen work because `absent(Y)` and `present(Y)` can never both be true. When both conditions could hold, make them exclusive by adding `absent` of the clause that takes precedence to the other clause, as Unicorn does: its Princess clause beats its Empress, Queen, or Enchantress clause. Which clause takes precedence is a rules call, so ask if the card or the user hasn't settled it.

**"with X" versus "for each X".** `when` applies once however many cards match. `per` scales with the count. Getting these confused produces plausible scores, so check it for every clause.

## Engine behaviour worth knowing

All of this comes from `src/domain/score.ts`:

- **A card never counts itself, with two exceptions.** `per` and `when` only look at the other cards, except that `allSuitsDifferent` includes the owner's suit, and `baseStrengthRun` includes the owner's strength. So printed "other" ("each other Leader") needs no extra modelling. It also means a Leader's "with a Leader" needs a second Leader.
- **A blank never hits the card that owns it.** "All Beasts" on a Beast means the other Beasts.
- **A blanked card has no effect on other cards.** It has no name, suit, base strength, bonus or penalty. When points are added up, it gives none, satisfies no `present` condition, and counts as missing for `absent`, so blanking a card can trigger someone else's penalty. Clearing and blanking have already happened by then, as below. These rules are quoted at the top of `score.ts`, so don't weaken them.
- **Blanks that target other cards are simultaneous.** A card that still blanks at that point blanks everything it targets, even if another card blanks it. If A blanks B and B blanks C, both B and C are blanked. If two cards blank each other, both are blanked, whatever order they're in.
- **Self-blanks come after those.** Their conditions only see cards that other cards didn't blank, so a blanked Army can't save a card that needs one, and a blanked Weather can't blank a card that avoids it. They're all checked at once, so one self-blanked card can still satisfy another card's self-blank condition. A self-blanked card has already blanked its targets by then. This order is our interpretation of the rulebook, noted in `score.ts`.
- **Clears apply before anything else, from the full hand.** The rulebook says clearing comes before any penalties are applied. So a cleared penalty can't blank the card that cleared it, and a clearer that's later blanked has still cleared. A cleared card keeps its suit, name, base strength and bonus. Only bonus-slot `clearPenalty` effects count, because the rulebook calls clearing a kind of bonus.
- **`clearPenaltySuitWord` changes penalty effects, not card text.** It runs with the other clearing, from the full hand, on other cards' penalties only. A blank loses that target, along with any exception on it, and keeps the rest. An effect that counts or sums the suit, or whose condition names it anywhere, stops applying altogether. Matchers naming a specific card are untouched, even if that card is of the suit.
- **Bonus and penalty score the same way, but only penalties can be cleared.** Keep each effect in the slot the card prints it in.
- **Pre-scoring effects fire first, only for cards the variant lists, in its order.** Each listed card in the hand checks its choice against the hand the cards before it left, then fires its `preScoring` effects. Everything else about the card, including its bonus and penalty, is handled with the other cards. A card the variant doesn't list never fires its pre-scoring effects, and blanking or clearing can't stop one that is listed.
- **A choice is checked once,** at the card's pre-scoring step if it has one, or otherwise against the hand after pre-scoring. Island's is checked that way, and its clear applies when penalties are cleared.
- **Unknown effect kinds silently score 0.** `effectPoints` returns 0 for anything that isn't `points`, and `isBlanked` only looks at `blank`. A new kind compiles and does nothing until the engine handles it, which is why the test comes first.

## Wording the model can't express yet

Each of these goes through the propose-and-confirm step in `SKILL.md`.

| Printed idea                                                                                                                      | What's missing                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Clearing a word from penalties that isn't a suit                                                                                  | `clearPenaltySuitWord` only removes a suit                                                                                   |
| Other whole-hand or threshold rules: odd strengths, N of one suit                                                                 | apart from `allSuitsDifferent` and `baseStrengthRun`, effects only ask whether a card matches, not about the hand as a whole |
| Values read from other cards, other than summing base strengths: "the highest base strength", "the base strength of any one card" | `points` is a fixed number, and `sum` only adds up its matching cards                                                        |
| Changing identity: new suit or name, duplicating a card                                                                           | `matches` reads a card's printed suit and ID                                                                                 |
| Player choices other than a card in the hand or from the discard area                                                             | `CardChoice` has only the kinds `cardInHand` and `cardInDiscardArea`                                                         |

Resolution order matters for several of these. An effect that changes what other cards are (identity changes) or what their penalties say (clearing a word) has to resolve before blanking, because blanking depends on the result. Say which order you're proposing, and ask if the printed text doesn't settle it.

## Extending the engine

For anything that doesn't need player input, the change stays in the domain:

1. Add the variant or field to `CardEffect` in `src/domain/card.ts`. Keep it plain, serialisable data.
2. Write failing tests in `src/domain/score.test.ts`, using its synthetic cards (`card("subject", "wizard", 1, [...])`) in a new `describe`, never real cards. Cover the interactions with blanking, `per` and `when`, not just the simple case.
3. Implement it in `src/domain/score.ts`.
4. Add a helper to `card-definitions.ts`. It may only use `import type` from the domain, because infrastructure can't call domain functions.

`LoadCardsUseCase` replaces each ability with its text, so new effect data stays out of the UI automatically. A new top-level field on `Card` isn't filtered: `toCardView` spreads it into store state. Put new data inside `effects` where you can.

**Player choices are a bigger change.** The choice has to reach `ScoreHand`, so its input changes, and the choice needs state and UI, following UI -> thunk -> use case as `CLAUDE.md` describes. Say so plainly in the proposal instead of presenting it as a small engine tweak.
